# vBread
vBread is an ESP32 powered, 3x3 API buttonboard for VTube Studio. Toggle expressions, manage scenes, re-calibrate, and more using just a low-cost microcontroller.

<img width="500" alt="image" src="https://github.com/user-attachments/assets/0507def6-7919-446a-aa9d-ed1a04e6d01e" />

> Img Credit: VTube Studio, Denchisoft.

vBread supports multi-press combination toggles. Expression toggles are customizable using a web interface.
